# RS485 Tank Monitoring System

An industrial-grade embedded monitoring system designed for real-time water tank level measurement using ultrasonic sensing and RS485 communication.

## Overview
This project measures water level inside storage tanks using ultrasonic sensing technology and transmits data over RS485 for reliable long-distance industrial communication.

The system is designed for robust remote monitoring in automation and smart water management applications.

## Features
- Real-time tank level monitoring
- Ultrasonic distance sensing
- RS485 long-distance communication
- Industrial noise-resistant data transmission
- Embedded microcontroller processing
- Scalable multi-node deployment
