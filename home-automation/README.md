# Home Automation System

A smart embedded home automation solution designed for remote monitoring and control of household devices using microcontroller-based firmware and wireless communication.

## Overview
This project focuses on building an intelligent automation platform for controlling electrical appliances and monitoring environmental conditions in real time.

## Features
- Remote device switching
- Sensor-based automation
- GSM/Wi-Fi control
- Real-time status monitoring
- Embedded firmware control
- Automated decision making

## Hardware Used
- ESP32 / Arduino
- Relay modules
- GSM / Wi-Fi module
- Sensors
- Power regulation circuitry

## Software & Tools
- Embedded C / C++
- VS Code / Arduino IDE
- Serial debugging tools

## Applications
- Smart lighting
- Automated curtains
- Appliance control
- Environmental monitoring
